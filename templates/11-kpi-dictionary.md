# GEO KPI 字典

## 有效样本口径
一次有效测试 = 事前固定的问题 + 指定平台/地区/时间 + 确认该平台实际生成了可观察的答案 + 保留原文/截图。未触发 AI 答案的情况独立记录。

| 指标 | 定义 | 分母 | 不能推导什么 |
|---|---|---|---|
| 品牌提及率 | 被提及的有效回答数量 / 有效回答总数 | 有效回答 | 不等于推荐率或成交率 |
| 自有域名引用率 | 引用自家 URL 的有效回答数量 / 有效回答总数 | 有效回答 | 不等于流量 |
| 被引用页面数 | 去重后的自有 URL 数量 | 无 | 不等于展示次数 |
| AI 搜索来源点击 | 实际分析系统识别的来源访问 | 访问会话 | 部分 AI 来源可能被误归类 |
| GEO 来源有效线索 | 真实可核对的归因线索数 | 线索 | 不等于完全因果归因 |
| 转化率 | 实际成交数 / 同口径有效线索数 | 有效线索 | 不等于 ROI |

## 平台数据优先级
1. Google Search Console 生成式 AI 报告（覆盖范围与界面以实际账号为准）。
2. Bing Webmaster Tools AI Performance。
3. 网站 Analytics、表单和 CRM。
4. 固定问题库人工复测（仅抽样观察，不代表平台整体）。

写清基线与对照时间段、设备和国家；严禁用“1 次命中 / 1 次测试 = 100% 推荐率”做宣传。
