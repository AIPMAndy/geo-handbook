# 第 09 章：站点地图、规范链接与索引

类别：技术

帮助搜索系统发现真正应该收录的页面，并避免重复 URL 分散信号。

## 5 个动作

1. 列出核心可公开页面及唯一规范 URL。
2. 生成 XML sitemap，仅包括实际可访问的规范页面。
3. 检查 canonical、重定向、404/软404和移动端访问。
4. 在 Google Search Console / Bing Webmaster Tools 验证网站并提交 sitemap。
5. 记录已发现、已索引、未索引的实际状态，区分提交与收录。

## 交付与验收

《索引台账》与 sitemap.xml。

## 易错点

宣称提交 sitemap 或普通网页调用 Google Indexing API 能保证收录。
