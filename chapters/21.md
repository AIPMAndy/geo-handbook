# 第 21 章：Bing / Copilot 与 IndexNow

类别：平台

Bing Webmaster Tools 提供 AI Performance 视图；IndexNow 是更新通知协议，不是 AI 引用保证。

## 5 个动作

1. 在 Bing Webmaster Tools 验证域名并查看抓取和索引。
2. 有条件时查看 AI Performance 的页面、引用与 query 视图。
3. 确认站点支持 IndexNow 后按官方配置 key 与 URL 提交。
4. 记录被接受的提交与最终实际索引、引用结果。
5. 针对被引用的具体页面检查信息准确性与咨询入口。

## 交付与验收

《Bing/Copilot 观察记录》。

## 易错点

把 IndexNow “已收到提交”误写成“已被 AI 引用”。
