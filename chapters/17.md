# 第 17 章：GitHub、文档与技术品牌内容

类别：增长

对开发者工具、API 和技术服务，公开可运行示例比空泛介绍更容易建立信任。

## 5 个动作

1. 为真实开源项目写清楚安装、示例、许可证和维护状态。
2. 准备 5 分钟可复现的 Quickstart；在干净环境里验证。
3. 提供错误排查、FAQ 和真实变更日志。
4. 从官网产品页链接到官方仓库和文档，再反向链接回官网。
5. 在项目 README 中标注测试环境与最后更新日期。

## 交付与验收

《可运行 Quickstart》和完整 README。

## 易错点

贴一个不能运行的 demo 再宣传“已验证生产可用”。

> 更新时间：2026-11-05。场景演练均为假设示例，不代表已获得平台推荐。
