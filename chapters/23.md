# 第 23 章：指标定义与效果归因

类别：测量

引用、曝光、点击、线索和成交属于不同漏斗层级，必须分别测。

## 5 个动作

1. 定义提及率＝提到品牌的有效回答数÷有效测试回答数。
2. 定义引用率＝出现自有有效 URL 的回答数÷有效测试回答数。
3. 用 Search Console、Bing、站点 Analytics 与 CRM 分别记录能获得的数据。
4. 为咨询入口设置 UTM，并询问客户最早如何发现你。
5. 复盘时将算法波动、季节性、内容发布等并列为可能原因。
