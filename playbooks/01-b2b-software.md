# 行业路线 01｜B2B SaaS / AI 工具

**第一周**：客户访谈收集购买前的问题（集成、权限、安全、价格、替代方案）；固定 30 问和初始 AI 引用基线。

**第二周**：优先完成技术文档、可运行 Quickstart、对比页、集成说明、真实案例。不能展示“假 GitHub 星标”和虚构客户名单。

**第三周**：校验 API docs、版本号、错误示例、结构化数据和从答案页到注册页的入口。提供无需登录的公开说明与需要授权才能访问的私有部分。

**第四周**：同问题复测、记录实际来源 URL、试用注册/演示预约；与广告、老客户推荐分开统计。

验收：≥ 1 份可运行 Quickstart；≥ 1 篇有真实证据的比较页；30 条测试原始记录；1 份不夸大归因的复盘。
