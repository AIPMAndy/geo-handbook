# LAB 09｜品牌实体一致性与第三方资料

> 所属模块：信任建设｜更新时间：2026-11-05｜性质：可复现实验，绝非 AI 引用保证。

## 你做完会得到什么

让客户和信息检索系统看到一致、可核对的主体信息。

## 准备（0–5 分钟）

只需电脑和网络浏览器、自己有权限的站点（部分实验无网站也能完成）。用 `docs/` 打开网站，用 `templates/` 保存可编辑文件；所有客户信息请先去标识化。

## 按顺序实操

### 1. 建立事实表

写官方品牌名、主体、官网、服务、地区、联系方法及最后核对时间。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 2. 审核自有入口

官网主页、关于页、服务页、GitHub README、X/Threads 等统一描述。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 3. 纠正旧资料

优先更新你能管理的页面；外部页面错误通过正常联系渠道申请更正。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 4. 积累真实第三方引用

发布原创研究、真实合作内容和授权评价；保留独立第三方 URL。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 5. 记录关联与证明

每条引用写清发布者、日期、关系、链接、证据；不要购买虚假评论。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

## 最终验收（必须具备）

一份品牌事实表、5 个来源 URL 和修正前后截图。

## 常见失败和处理

自己控制的账号在同一天互相发同一篇文案，并不等于五个独立权威背书。

如果无法访问某个平台或没有后台权限：填写「未执行 / 无权限 / 无数据」，保留截图和阻塞原因，继续做不依赖权限的部分。不要凭空补零。

## 进阶实操：可直接抄的细节与排障

### 事实表必须能经得起交叉审查

第一列写品牌官方名称，第二列写对外简称、英文名，第三列写公司主体，后面依次是官网 URL、主营服务、服务地区、售后联系人和信息审核日期。每一格的事实应当有一个可信的原始依据；同一主体多个品牌可以明确关系，但不要混写成同一家公司。价格与授课节数若已经调整，最好在页面注明生效日期。

### 第三方来源如何排序

官网/官方 README 用于确定主体事实；合作伙伴页面可以证明真实合作关系；独立媒体研究与授权评价可能提供外部视角；自营的多个社交账号只能算同一主体发布的不同入口。收集外部证据不是为了堆数量，而是修复信息缺失与矛盾。完全没有第三方提及时，先发布真实研究和有价值的公开资源，让自然引用有合理理由。

### 反向核验

随机抽 5 个在搜索里可见的入口，请一位陌生读者回答「这是谁、提供什么、去哪里联系、信息是否互相冲突」。不能一致回答，就先修事实页，而不是追求更多关键词。
