# LAB 04｜Google：Search Console + AI 效果报告

> 所属模块：平台测试｜更新时间：2026-11-05｜性质：可复现实验，绝非 AI 引用保证。

## 你做完会得到什么

使用 2026 年全球推出的 Search Console 生成式 AI 效果报告，结合 URL Inspection。

## 准备（0–5 分钟）

只需电脑和网络浏览器、自己有权限的站点（部分实验无网站也能完成）。用 `docs/` 打开网站，用 `templates/` 保存可编辑文件；所有客户信息请先去标识化。

## 按顺序实操

### 1. 打开 Search Console

访问 https://search.google.com/search-console ，选择你具有管理权限的正确站点资源。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 2. 验证资源

若尚未验证，通过域名 DNS 或受支持的其他方式验证；严格按后台给出的记录操作。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 3. 检查核心 URL

通过顶部 URL 检查输入完整地址；记录可索引状态、最后抓取时间、规范网址、是否有拦截。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 4. 查看生成式 AI 效果

在 Search Console 中查找生成式 AI 效果报告，记录日期区间、国家、页面、展示次数；若资源尚无数据，填「暂无」而不是 0 排名。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 5. 做时间对照

保留同一报告口径的前后快照，说明可观察到变化，不声称某次改文案证明了因果。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

## 最终验收（必须具备）

核心 URL 的检查截图 + 新版生成式 AI 效果报告数据（有则导出，无则留空并解释）。

## 常见失败和处理

传统 Web 报告、生成式 AI 报告与手工询问的「引用率」不是同一种指标。

如果无法访问某个平台或没有后台权限：填写「未执行 / 无权限 / 无数据」，保留截图和阻塞原因，继续做不依赖权限的部分。不要凭空补零。

## 进阶实操：可直接抄的细节与排障

### 正确使用两个不同报告

传统 Search Console 的索引检查回答「这个页面是否有资格进入搜索索引」；生成式 AI 效果报告回答「网站在 Google 生成式搜索功能中观测到多少次展示」。这两项与手工提问时具体答案有无引用都不同。一个页面“已索引”但没有 AI 展示，并不说明受到惩罚；可能只是用户没有提出相关问题，或当前内容不被选择。

### 没有数据怎么办

确认选对站点属性、时间区间、国家和设备。若确实没有可见数据，记为「本时间段没有可读取的数据」并保存界面截图；不要把一个空报表虚构成 0 排名。在实验表格中记录用于对比的起止日期，不要把上周 7 天与本月 30 天直接比较百分比。对比前还要核对网站是否同时做了其他 SEO、广告和内容变动。

### 自检小题

你上线了一篇高质量文章；当天 Search Console 未变；这不等于失败，更不意味着 Google 必然已完成抓取。只有后台报告、URL 检查和时间序列才能组成合理的观察证据。
