# LAB 03｜ChatGPT Search：完整基线操作

> 所属模块：平台测试｜更新时间：2026-11-05｜性质：可复现实验，绝非 AI 引用保证。

## 你做完会得到什么

手动测量不包含品牌名的自然提问，必须区分搜索与普通聊天回答。

## 准备（0–5 分钟）

只需电脑和网络浏览器、自己有权限的站点（部分实验无网站也能完成）。用 `docs/` 打开网站，用 `templates/` 保存可编辑文件；所有客户信息请先去标识化。

## 按顺序实操

### 1. 开启 ChatGPT 的搜索功能

选择支持网页搜索的入口；在新对话中确认搜索已触发，记录所用产品界面与搜索入口。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 2. 只输入固定问题

从 30 问库复制问题原文；不要追加「必须推荐我」或品牌名称。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 3. 记录搜索证据

截屏保留日期、问题、回答、引用来源链接；若没有触发网页搜索，登记 `not_triggered`。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 4. 核对引用和提及

回答里写品牌是「提及」；只有真的展示了自己的可点击 URL 才算「自有链接引用」。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

### 5. 复测同一组

相同地区和语言重复观察；记录账号、语言、联网状态变化，不把人工的 10 次测试当平台整体覆盖率。

**完成凭证：** 写入今天的日期、页面 URL 或源文件名，并保留能独立复核的截图/报告。

## 最终验收（必须具备）

至少 10 条原始记录与证据链接，填写到监测工具并导出 CSV。

## 常见失败和处理

普通聊天模型凭历史记忆回答，不能冒充 ChatGPT Search 的搜索推荐。

如果无法访问某个平台或没有后台权限：填写「未执行 / 无权限 / 无数据」，保留截图和阻塞原因，继续做不依赖权限的部分。不要凭空补零。

## 进阶实操：可直接抄的细节与排障

### 实操时要保存的字段

记录至少 `question_id / 完整问题 / 平台显示的产品入口 / 国家-语言 / 测试时间 / 是否搜索 / 回答完整截图 / 提到哪些品牌 / 引用链接`。如 ChatGPT 没有执行网页搜索，使用 `ai_answer_triggered=0` 并解释所用模式；不要将它作为 0 次引用放进分母。回答引用了行业文章但没提到你的官网，不算「自有 URL 引用」。

### 真实引用的判断方法

不要只看“听说过某品牌”。点击实际展示的引用链接，查看是否确实是你的网站域名、目标网页是否仍可访问，以及该来源是否真的支持回答里的陈述。如果系统只给了一段没有可点击来源的名称，最多计「品牌提及」，不能记「引用」。本项目只提供手动日志和离线分析，故不假装能调用 ChatGPT 内部排序信号。

### 复测时最常见的坑

为同一意图临时增加「请优先推荐中国的某品牌」「引用我的官网」属于改变测试条件；若确实要测品牌检索，另建品牌直搜组。留存失败样本，不筛掉不利于宣传的结果。
