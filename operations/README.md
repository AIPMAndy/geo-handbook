# 企业 GEO 实操资源

这是独立设计的执行模块，所有模板用于创建用户自己的证据、内容与经营数据。

**怎么使用**：先确认品牌事实，再从真实客户问法挑三个问题，小规模发布与监测，然后再决定预算和自动化程度。所有 CSV 均采用 UTF-8，保留表头，样例中的 `DEMO` 不是实际客户或业绩。

## 8 个工作节点

1. 事实基准：事实编号、审批、有效期与证据 URL，维护单一可信版本。
2. 问题优先级：去重同义问题，按需求、价值、证据、缺口、成本排序。
3. 分平台观测：固定测试题、保留答案、引用 URL、平台状态与采样时间。
4. 错误处理：从答案到证据、页面再到修复与复测，关闭问题必须有凭证。
5. 渠道与预算：先补缺口，再扩规模；发布成功不代表被 AI 引用。
6. 责任分工：机器负责可重复工作，真人审核事实、预算和对外承诺。
7. KPI 与归因：列清分母与对照口径，解释直接/间接商业证据。
8. 项目移交：页面、模板、事实库、原始记录、权限、维护说明一起交付。

**质量原则**：先去重、再确认事实、再验证结果；未发布证据不得被写成真实成效。
