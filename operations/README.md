# GEO 实验室：可复核的网页与 AI 搜索实验

这一部分不是行业观点摘录，而是可以从一张真实网页、一条真实客户问题开始的验证工具。每一轮只解决一个可观察的问题，记录完整过程，再做继续、调整或停止的判断。

## 六步实验

| 实验 | 用户完成的动作 | 能拿到的证据 |
| --- | --- | --- |
| E01 | 固定问题、实验条件和预期观察 | 带对照条件的实验登记表 |
| E02 | 检查网页的可访问性、元数据和引用凭据 | 页面技术快照 |
| E03 | 在指定平台保存改动前回答 | 可追溯的原始答案记录 |
| E04 | 修改一个网页因素并保留旧版本 | 带版本号的变更台账 |
| E05 | 同条件复测、分平台复核引用与提及 | 继续 / 调整 / 停止的记录 |
| E06 | 记录真实访问或咨询，不强行归因 | 业务事件证据清单 |

建议从 E01 连续做到 E06，而不是一次性批量生成很多页面。无法提供客户原始问题时，先做访谈；没有基线样本时，不应声称「内容上线带来增长」。

## 复现实验规范

- **最小单位**：一个问题、一项网页改动、一个可比较的样本组。记录模型、地区、日期、是否触发联网以及实际回答。
- **可复核产物**：变更版本、页面 URL、原始问答与引用网址，放在自己控制的文件夹或仓库；模板本身不上传用户数据。
- **判断标准**：直接比较同条件有效样本中的提及和引用，分平台列出分子、分母与时间窗；不宣称确定性排名。
- **业务核验**：咨询和成交使用真实事件，区分可追踪、用户自报和来源不明。没有证据的转化，不拿来计算 ROI。
- **隐私边界**：公开样例均标注 `DEMO-`；真实客户记录只在取得授权后使用；公开模板不存个人信息。
